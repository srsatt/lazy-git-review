## Measured scope and limitations

- Inker acceptance covered 82 hunks, 9,285 nodes, and 5,408 edges: cold graph 15.36 seconds, cached graph 0.66 seconds, and overview 0.13 seconds. Full metrics and ranking evidence are in [acceptance/README.md](README.md).
- Semantic profiles are qualified for TypeScript/JavaScript, TSX/JSX, HTML, and CSS. Unsupported LSP relationships remain explicit; no complete cross-language or runtime dependency claim is made.
- Published native targets are macOS Apple silicon and Linux x86-64. Git, qualified language-server runtimes, and optional Neovim/GitHub integrations remain external dependencies documented in `docs/`.
- GitHub 0.1.0 publishes new reviews and drafts. Remote reply, edit, and thread-resolution synchronization remain outside this release.
